How the mutex is applied

lock = threading.Lock()

def register(event, user):
    lock.acquire()            # ENTRY section
    try:
        # ---- CRITICAL SECTION ----
        if seats_taken(event) >= capacity: return FULL
        if already_registered(user):       return DUPLICATE
        save_registration(event, user)
        # --------------------------
    finally:
        lock.release()        # EXIT section
  • Shared data: remaining capacity of each event.
  • Race condition: two users both read “1 seat left”, both write → overbooked.
  • Critical section: check capacity → check duplicate → insert.
  • Mutex: only one request inside at a time; others wait, then see the updated count.
  • Cancellation also takes the lock because it changes capacity.
